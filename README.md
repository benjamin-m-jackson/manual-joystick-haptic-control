# Data and analysis code

For the article **Manual, Joystick, or Haptic Control? An In Vitro Comparison of Navigation Strategies for Robotic Interventional Neuroradiology Procedures**.

This package contains the de-identified participant-level data from the user study and the scripts that reproduce every statistic, Table I, and Figs. 6–13 of the article.

## Contents

| Path | Contents |
|---|---|
| `data/` | De-identified data. See `data/DATA_DICTIONARY.md`. |
| `scripts/` | Analysis scripts (below). |
| `output/` | Results generated by the scripts: `results_values.csv` (every reported number, by key), `model_summaries/` (full model output), `table1_qual_master.tex` (Table I), `figures/` (Figs. 6–13), `manuscript_value_audit.csv` (check of every number in the article text). |
| `environment.yml` | Software versions used. |
| `LICENSE`, `data/LICENSE` | MIT (code); CC BY 4.0 (data and results). |

## Reproducing the results

```
conda env create -f environment.yml
conda activate tmrb-r2-analysis
python scripts/run_all.py
```

The scripts read only `data/` and write to `output/`. Running them reproduces the files in `output/`.

| Script | Reproduces |
|---|---|
| `01_time_models.py` | Navigation time (Sections IV-A1, IV-B1): descriptives, navigations stopped at the eight-minute limit, linear mixed model, censored Cox sensitivity analysis |
| `02_count_models.py` | Incorrect catheterizations and prolapse events (Sections IV-A3, IV-A4, IV-B3, IV-B4): Poisson GEE with the Mancl–DeRouen small-sample correction (reported) and the robust sandwich covariance (for comparison) |
| `03_force_models.py` | Vessel-wall force (Sections IV-A2, IV-B2): linear mixed models, per-sensor novice–expert models, and sensitivity analyses |
| `04_questionnaire_table1.py` | Table I and the questionnaire statistics (Section IV-C) |
| `05_figures.py` | Figs. 6–13 (see the table below) |
| `06_check_manuscript_values.py` | Checks every number quoted in the article text against `output/results_values.csv`. It needs the manuscript source, so `run_all.py` skips it here; its result is included as `output/manuscript_value_audit.csv`. |
| `common.py` | Shared data loading and model helpers |

## Notes

- Participant codes (P01–P09) are random. The key is held by the study team and is not released.
- For three navigations, the force log analysed in an earlier version of the manuscript was a recording of a practice or preview run. The trial's own log is used here (see `data/DATA_DICTIONARY.md` and `data/missing_and_excluded.csv`).
- The files in `model_summaries/` record the date and time of each run, so they differ trivially between runs.
